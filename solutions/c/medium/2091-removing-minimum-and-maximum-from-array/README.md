# 2091. Removing Minimum and Maximum From Array

- **Difficulty:** Medium
- **Link:** https://leetcode.com/problems/removing-minimum-and-maximum-from-array/

Given an array, return the minimum number of deletions required to remove both the minimum and maximum elements. You can delete from the front or the back of the array.

- Time complexity: O(n)
- Space complexity: O(1)

Example

Input: [2,10,7,5,4,1,8,6]
Output: 5

Explanation: Remove first 2 elements and last 3 elements (total 5 deletions) to remove both min (1) and max (10).
